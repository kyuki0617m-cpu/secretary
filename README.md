# マイ秘書（自分専用の秘書アプリ）

Node.js の標準機能だけで動く、メモ・タスク管理・ダッシュボードのアプリです。
外部パッケージのインストールは不要です（`npm install` は要りません）。

## 起動方法

PowerShell で次を実行します。

```
& "C:\Program Files\nodejs\node.exe" "C:\Users\yuki0\Desktop\claudecode\secretary\server.js"
```

起動したらブラウザで <http://localhost:3000> を開いてください。
終了するときは、実行中のウィンドウで `Ctrl + C` を押します。

`node` に PATH が通っている環境なら、このフォルダで `node server.js` だけでも起動できます。
ポートを変えたいときは `PORT` を指定します（例: `$env:PORT=3001` してから起動）。

## 機能

- **ダッシュボード**（画面上部）: メモの件数 / タスクの件数 / 未完了タスクの件数、および最新の週次振り返り。
  件数のタイルや振り返りをクリックすると、その一覧までスクロールします。
- **メモ**: タイトルと本文を入力して追加、一覧表示、作成日時の表示
- **タスク**: 入力して追加、一覧表示、チェックボックスで完了済みに（もう一度押すと未完了に戻せます）、削除、作成日時と完了状態の表示
- **週次の振り返り**: 週（月曜〜日曜）を選んでコメントを記録、一覧表示、記録日時と更新日時の表示。
  1つの週につき1件で、同じ週にもう一度保存すると上書き（＝編集）になります。記録済みの週を選ぶと、その内容が入力欄に読み込まれます。

## データの保存先

同じフォルダの `data.json` に自動保存されます。アプリを閉じても内容は残り、次に起動したときに読み込まれます。
バックアップを取りたいときは `data.json` をコピーしてください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `server.js` | HTTP サーバーと API、`data.json` への読み書き |
| `index.html` | 画面（ダッシュボード・メモ・タスク） |
| `data.json` | 保存されたメモとタスク（初回の追加時に自動作成） |

## API（画面が内部で使っているもの）

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET | `/api/data` | メモ・タスク・振り返りを取得 |
| POST | `/api/memos` | メモを追加（`{ title, body }`） |
| POST | `/api/tasks` | タスクを追加（`{ title }`） |
| PATCH | `/api/tasks/:id` | 完了状態を変更（`{ done }`） |
| DELETE | `/api/tasks/:id` | タスクを削除 |
| POST | `/api/reviews` | 週次の振り返りを記録・上書き（`{ weekStart, comment }`） |

`weekStart` は `YYYY-MM-DD` 形式で、週内のどの日付を送っても、その週の月曜日に揃えて保存されます。

サーバーは `127.0.0.1`（自分のPCの中）だけで待ち受けるため、外部からはアクセスできません。
